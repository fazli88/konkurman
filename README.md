# پاسخبرگ کنکور من — پروژه اندروید

این پروژه نسخه آفلاین HTML را داخل Android WebView بسته‌بندی می‌کند. داده‌ها با `localStorage` خود WebView روی دستگاه نگهداری می‌شوند و مجوز اینترنت در Manifest وجود ندارد.

## قابلیت‌های اضافه‌شده
- داشبورد تست روزانه، هفتگی، کل تست‌ها و رکورد بیشترین تست در یک روز
- نمودار هفت روز اخیر و میانگین درصد آزمون‌ها
- کتابخانه تست با امکان افزودن و حذف کتاب و ثبت درس/ناشر/توضیح
- اتصال هر آزمون به کتاب انتخاب‌شده
- تاریخچه کارنامه‌ها و ثبت تاریخ، تعداد درست/غلط/نزده و درصد
- ذخیره دائمی پاسخبرگ‌ها و پاسخ‌های در حال انجام
- خروجی و بازیابی فایل پشتیبان JSON
- حفظ امکانات نسخه اولیه: تایمر، پاسخبرگ، کلید، تحلیل، تست آموزشی و خروجی PDF/تصویر

## ساخت APK در Android Studio
1. Android Studio را نصب و این پوشه را با گزینه **Open** باز کنید.
2. در صورت درخواست، Android SDK Platform 35 و JDK 17 را نصب کنید.
3. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** استفاده کنید.
4. فایل خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

حداقل نسخه اندروید: Android 6.0 (API 23). برنامه برای کارکرد عادی به اینترنت نیاز ندارد.

## نکته ذخیره‌سازی
پاک‌کردن داده‌های برنامه یا حذف نصب، داده‌های محلی را پاک می‌کند. از دکمه «خروجی پشتیبان اطلاعات» در داشبورد، مرتب فایل JSON بگیرید و در جای امن نگه دارید.
